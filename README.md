# Chai Ledger

Daily tea and coffee vendor management app. Single HTML file, no server, no build step.

## Features
- Dashboard with today's and the month's summaries
- Calendar: pick any date to view its records
- Daily entry for morning and evening sessions (tea cups, coffee cups)
- Edit or delete any saved entry
- Common tea and coffee prices with an edit option (a price change updates every entry)
- Excel (.xlsx) export of the month or all records

## Run
Open `index.html` in a browser. It works offline.

## Data
Records and prices are stored in the browser's local storage on your device. Use the same browser each time and don't clear site data. Download the Excel file now and then as a backup.

## Host on GitHub Pages
Repository Settings > Pages > Deploy from a branch > `main` / root.
